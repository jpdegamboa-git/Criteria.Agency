# Client Portal — UX/UI Design Spec

> Date: 2026-04-08
> Status: Design approved, pending implementation plan

---

## 1. Overview

The Client Portal is the primary interface for criteria.agency customers. It allows clients to manage their brands, plan marketing strategy, execute campaigns, track sales, and interact with the AI Copilot — all from a single, clean dashboard.

**Design principles:**
- Progressive disclosure: PyME sees simplicity, Mediana gets more controls
- Copilot-first: AI assistant always available, drives onboarding
- Data-forward: big numbers, actionable insights, gap detection
- Harvard-aligned: funnel stages, KPIs, and budget allocation follow Harvard M1-M6 frameworks

**Design style:**
- Clean white backgrounds with subtle dot pattern texture (radial-gradient, rgba(0,0,0,0.15), 0.8px, 20px grid)
- Minimal shadows (0 1px 3px rgba(0,0,0,0.04))
- Bold typography for KPIs (28px, weight 800, Inter font)
- Lucide Icons (line/outline, rounded stroke)
- Light mode default, dark mode toggle available
- Reference: PilePeak.ai dashboard style

## 2. Architecture

### 2.1 Routes

```
/client
  ├── /                    (Home — KPIs, ideas, opportunities, charts, feed)
  ├── /brand               (Identity, guidelines, guardian, positioning)
  ├── /plan                (Strategy, budget allocator, audiences, markets, opportunities, studies)
  ├── /campaigns           (Funnel matrix, calendar gantt, list, campaign detail)
  │   └── /[id]            (Campaign detail — activations, stepper, artifacts)
  ├── /sales               (Pipeline kanban, leads, proposals, attribution)
  └── /setup               (Account, team, billing, integrations — via avatar dropdown)
```

### 2.2 Auth

- New role: `client` (separate from `admin`)
- Multi-brand support: one client account can manage multiple brands
- Brand selector: dropdown per space (not global)

### 2.3 Layout

- **Top nav bar:** 5 tabs (Home, Brand, Plan, Campaigns, Sales)
- **Right side of nav:** Theme toggle (light/dark), Notifications bell (with badge + dropdown), Avatar with dropdown (name, Setup link, sign out)
- **Copilot:** Floating action button (bottom-right), opens as right-side drawer (~350px)
- **Background:** Dot pattern texture on light gray (#f5f5f7)
- **Content:** Max-width 1140px, centered

## 3. Home

### 3.1 Header
- Greeting: "Buenos días, {name}"
- Subtitle: "{n} campañas activas y {n} oportunidades nuevas"
- CTA button: "Copilot" (gradient brand color, opens drawer)

### 3.2 KPI Cards (4 columns)
- Campañas activas (count + delta)
- En producción (count + breakdown by type)
- Leads este mes (count + % change)
- Brand score (number/100 + delta)

### 3.3 Ideas para ti (2/3 width)
- 3 campaign ideas generated by Copilot based on brand, industry, season
- Each card: icon area, title, description, tags (type, channel, estimated time), "Crear →" button
- Urgency indicator for time-sensitive ideas (e.g., "⏰ 7 días")
- "Más ideas" refresh button
- 1-click launch: opens Copilot with pre-filled brief

### 3.4 Oportunidades (1/3 width)
- 3 opportunity cards from intelligence listeners
- Types: Tendencia, Competencia, Cultura
- Each card: type label with dot, title, description, action button (Crear contenido, Analizar, Aprovechar)
- "Ver todas →" link to Plan > Oportunidades

### 3.5 Charts (2 rows)
Row 1 (2 columns):
- **Rendimiento de campañas:** Area chart, alcance + engagement, filterable 7d/30d/90d
- **Funnel de ventas:** Horizontal bars (Visitantes → Leads → Calificados → Cerrados) + conversion rate

Row 2 (2:1 ratio):
- **Producción de contenido:** Stacked bar chart by month and type (videos, posts, emails)
- **Inversión mensual:** Donut chart with breakdown by category (producción, distribución, estrategia, ads)

### 3.6 Activity Feed (minimal)
- Reduced to light log at bottom, muted styling
- No filter pills — just a simple chronological list
- Each item: colored dot (by space) + description + time

### 3.7 Notifications
- Bell icon in nav with badge count
- Dropdown shows items requiring attention (gate reviews, proposal approvals, etc.)
- Each notification: dot, description, source space, time, action button

### 3.8 Empty State (Onboarding)
- Dashboard empty, Copilot drawer opens automatically
- Copilot greets user: "Cuéntame sobre tu negocio"
- Through conversation: configures brand, launches first project
- Suggested quick options: "Necesito un video", "Definir mi marca", "Un plan de marketing"

## 5. Plan

### 5.1 Sub-tabs
Estrategia | Budget | Mercados | Oportunidades | Estudios

### 5.2 Brand Filter
- Pill selector per space (not global)

### 5.3 Estrategia Tab
- **Marketing Plan:** Current plan with objectives, each with progress bar and metric
- **Audiencias:** Persona cards with segmentation (Principal, Secundaria, Nicho) — demographics, psychographics
- **Panorama competitivo:** Competitor cards with social metrics (followers, engagement, frequency), strength/weakness
- **Briefs activos:** Cards with status (En ejecución, Aprobado, Borrador), piece count, link to Campaign

### 5.4 Budget Tab — Equalizer System

Hierarchical budget allocator with cascading sliders:

**Level 1: Quarters**
- Annual budget split across Q1-Q4
- Sliders sum to 100% of annual budget
- Each quarter shows dollar amount

**Level 2: Funnel Stages (per quarter)**
- Awareness / Consideration / Conversion / Retention
- Sliders sum to 100% of quarter budget
- Shows dollar amount per stage

**Level 3: Channels (per funnel stage)**
- SEM, Social Ads, Display, Video/OTT, SEO/Content, Email, Social Org, Influencers
- Sliders sum to 100% of funnel stage budget
- Shows dollar amount per channel

**Level 4: Media Type (per channel)**
- Paid / Owned / Earned split
- Sliders sum to 100% of channel budget

**Behavior:**
- Adjusting a slider at any level automatically rebalances siblings (proportional or locked)
- Lock icon on individual sliders to prevent auto-adjustment
- Each level shows: slider, percentage, dollar amount, recommended range (from Copilot)
- Warning indicators when allocation deviates significantly from Harvard M6 recommendations
- These limits propagate to Campaigns — when creating an activation, available budget per matrix cell (channel × funnel stage) is shown

**Rabbit hole navigation:**
- Start at Quarter level
- Click into a quarter → see Funnel breakdown
- Click into a funnel stage → see Channel breakdown
- Click into a channel → see Media type breakdown
- Breadcrumb navigation: Q2 > Awareness > Social Ads > Paid

### 5.5 Mercados Tab
- Industry data, market size, macro trends
- Sourced from intelligence listeners

### 5.6 Oportunidades Tab
- Full feed from 4 listeners (Brand, Culture, Industry, Competitive)
- Filterable by type
- Each opportunity: type, title, description, action button
- Expanded version of what appears in Home

### 5.7 Estudios Tab
- Research generated by agents (competitive analysis, audits, benchmarks)
- Cards with date, type, summary, "Ver completo" link

## 6. Campaigns

### 6.1 Conceptual Model

- **Campaign** = thematic grouping of activations across channels and funnel stages (e.g., "Día de las Madres")
- **Activation** = a specific effort in one cell of the funnel matrix (e.g., "Meta Retargeting" in Conversion × Social Ads)
- **3 Campaign states:** Plan → Ejecutar → Seguimiento

### 6.2 Views (toggle in filter bar)
- **Matrix** — Funnel matrix (default)
- **Calendario** — Gantt chart
- **Lista** — Flat list of campaigns/activations

### 6.3 Filters

**Row 1 (grouped button bars):**
- Media type group: All | Paid (purple dot) | Owned (teal dot) | Earned (coral dot)
- State group: All | Plan | Ejecutar | Seguimiento
- Campaign dropdown: "All campaigns ▾" (lists all campaigns)
- View toggle (right-aligned): Matrix | Calendario | Lista

**Brand selector:** Dropdown aligned right at title level

### 6.4 Funnel Matrix View

**Structure:**
- Rows = Channels (SEM, Social Ads, Display, Video/OTT, SEO/Content, Email, Social Org, Influencers)
- Columns = Funnel stages (Awareness, Consideration, Conversion, Retention)
- Column headers show stage name + relevant KPIs (Impressions/CPM/Reach, Clicks/CTR/CPC, ROAS/CAC/Conv Rate, LTV/Churn/Ret Rate)
- Row labels show channel name, sub-description, and media type dot(s)

**Activation chips (in cells):**
- White card, no colored border
- Title colored by media type (purple=Paid, teal=Owned, coral=Earned)
- State badge (Plan/Exec/Track)
- KPI tags (gray pills with metric values)
- Click → navigates to campaign detail

**Empty cells:**
- "+" button with dashed border
- Hover: border turns brand color, suggests activation type

**Below matrix:**

**KPI Cards (4 columns):**
- One per funnel stage
- Big number (28px bold) + label + secondary metrics + trend
- Harvard M2/M6 aligned metrics

**Copilot gap analysis:**
- Card with lightbulb icon
- Identifies empty cells, suggests priorities
- "X gaps / Y total" count
- Actionable recommendation text

### 6.5 Calendario View (Gantt)

**Structure:**
- Rows = Campaigns (not activations)
- Columns = Weeks (displayed in quarter view by default)
- Time controls: Mes | Trimestre | Año + ← → arrows
- Current week highlighted

**Campaign bars:**
- Horizontal bars spanning duration
- Color by state: Plan (purple, dashed border), Exec (amber), Track (teal)
- Bar label: campaign name + objective metric
- Continuous campaigns (Newsletter, SEO) = gray bars spanning full period
- Click → navigates to campaign detail

**Below gantt:**
- Summary cards: Active campaigns by state, Q2 objectives with progress, Funnel coverage bar

### 6.6 Campaign Detail (/campaigns/[id])

**Header:**
- Breadcrumb: Campaigns / Campaign name
- Title, tags (type, channel, brand, created date)
- State badge
- Actions: Pausar, Hablar con Copilot

**Stepper (horizontal):**
- Pipeline progress for production campaigns (Brief → Concepto → Guion → Storyboard → Edición)
- Completed steps: teal checkmark
- Active step: brand color with number
- Pending steps: gray
- Gradient connector between completed and active

**Active Gate Card:**
- Highlighted border (brand color)
- Gate name + description (quality gate philosophy)
- State: "Esperando tu revisión"
- Actions: Revisar, Ver anterior, Pedir cambios

**Tabs:**
- Artifacts (grid of deliverables with version, status, open link)
- Historial (timeline of events)
- Comentarios (discussion thread)
- Métricas (campaign-specific performance data)

**Budget awareness:**
- Shows allocated budget vs. spent for this campaign
- Warning if approaching limit set in Plan > Budget

## 7. Sales

### 7.1 KPI Cards (5 columns)
- Leads (count + trend)
- Calificados (count + % of leads)
- Pipeline value (dollar amount + deal count)
- Won this month (dollar amount + deal count)
- Avg deal size (dollar amount + trend)

### 7.2 Filters
- View group: Pipeline | Leads | Proposals
- Temperature group: All | Hot (red dot) | Warm (amber dot) | Cold (purple dot)
- View toggle: Kanban | Lista

### 7.3 Pipeline Kanban
- Columns: New → Contacted → Proposal → Negotiation → Won
- Column headers: stage name, count, total value
- Won column: teal header border

**Deal cards:**
- Name + temperature dot
- Description
- Value (bold)
- Time since last activity
- Lead score bar (colored by temperature)
- Touchpoint tags (Email sent, WhatsApp, Called)
- Proposal cards: highlight border when waiting approval, "Auto-generated" tag

### 7.4 Lead Sources
- Horizontal bar chart
- Bars colored by media type (Owned/Paid/Earned)
- Shows channel name + lead count

### 7.5 Best Customers Origin (Attribution)
- Table: Customer name, revenue/LTV estimate, touchpoint journey (e.g., "Google Maps → Blog → Email"), touchpoint count, days to close
- Multi-touch attribution visualization

### 7.6 Copilot Insight
- Sales-specific recommendations
- E.g., "Referrals convierten 3x más rápido — crear programa de referidos"

## 8. Setup (Avatar Dropdown)

Accessed via avatar dropdown in nav, not a main tab.

### 8.1 Sections
- **Cuenta:** Company info, logo, plan tier, billing
- **Equipo:** Team members, roles, permissions (Mediana+ tier)
- **Integraciones:** Connected platforms (Google, Meta, Mailchimp, CRM, etc.)
- **Billing:** Subscription management, invoices, payment method
- **Autonomía AI:** Configure AI autonomy level per motor/campaign
  - "AI decides + human supervises" vs "AI recommends + human approves"
- **Apariencia:** Light/Dark mode toggle, language

## 9. Copilot

### 9.1 Behavior
- **FAB button:** Bottom-right, gradient brand color, always visible
- **Drawer:** Slides from right (~350px width), dashboard dims behind
- **Close:** X button or click outside

### 9.2 Capabilities
- Onboarding conversation (first-time empty state)
- Create campaigns from conversation
- Generate briefs
- Answer questions about metrics, performance
- Suggest optimizations
- Navigate user to relevant sections
- Pre-fill forms from conversation context

### 9.3 UI
- Chat bubble interface (Copilot messages in brand tint, user messages in white/gray)
- Quick reply buttons / suggested options
- Rich inline content (action cards, previews, metrics)
- Input bar at bottom with send button

## 11. Responsive Considerations

- **Desktop first** (1140px+ content area)
- **Tablet:** Matrix collapses to horizontal scroll, Kanban stacks, charts resize
- **Mobile:** Top nav → hamburger menu, Copilot → full screen, Matrix → card list view
- Progressive tier: PyME sees fewer KPIs/charts, Mediana sees full dashboard
