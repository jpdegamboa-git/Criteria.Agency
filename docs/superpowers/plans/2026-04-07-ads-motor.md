> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the Ads Motor (C-016) — register pipeline, create 5 agent skill files, wire up context maps, and update DB schema.

**Architecture:** Adds an `ads` pipeline to PipelineRegistry with 6 steps and 2 gates. Creates 5 agents (AD-L through AD-004). Orquestador puro: plans pauta, coordinates production via Writers Room and Graphic Design, defines targeting, and compiles launch kits.

**Tech Stack:** TypeScript, Drizzle ORM (PostgreSQL), Vitest, Hono
