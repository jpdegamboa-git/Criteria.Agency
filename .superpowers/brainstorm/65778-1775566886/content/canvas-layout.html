A. Full-width Canvas

El canvas ocupa todo el ancho bajo el nav bar. Filtros en una barra horizontal arriba del canvas. Sidepanel se abre como overlay desde la derecha.

  • Máximo espacio para el grafo
  • Consistente con el layout actual del admin
  • Sidepanel como drawer over el canvas

B. Immersive Canvas (Dedicated View)

El canvas es su propia vista inmersiva — sale del layout max-w-7xl del admin. Toolbar vertical a la izquierda, filtros flotantes, team clusters como zonas. Se siente como una app separada.

  • Experiencia tipo Figma/weavy — canvas-first
  • Toolbar vertical con herramientas
  • Nodos agrupados por equipo con zonas
  • Animaciones de partículas en edges

C. Split View (Canvas + Panel)

Layout dividido: canvas a la izquierda (~65%), panel de detalle siempre visible a la derecha (~35%). El panel cambia al seleccionar un nodo. No hay drawer/overlay.

  • Info siempre visible sin clicks extra
  • Menos espacio para el canvas
  • Familiar (tipo VS Code / IDE)
