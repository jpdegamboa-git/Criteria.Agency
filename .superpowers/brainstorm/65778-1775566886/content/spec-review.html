Agent Canvas — Design Spec

Revisa el spec completo. Haz click en las secciones que quieras modificar.

1

Overview & Stack

Canvas visual inmersivo estilo weavy.ai para 20 agentes. React Flow + Monaco Editor + SSE sobre Next.js 16 / React 19 / Tailwind v4 / Hono / Drizzle.

2

Architecture

canvas/
  page.tsx — Server component (fetch)
  canvas-view.tsx — Client (React Flow + SSE)
  components/
    agent-node.tsx, animated-edge.tsx, toolbar.tsx
    filter-pills.tsx, command-palette.tsx, minimap.tsx
  sidepanel/
    agent-drawer.tsx, agent-info.tsx, agent-editor.tsx, agent-executions.tsx

Data flow: page fetch → props → React Flow nodes/edges → SSE real-time → sidepanel lazy fetch

3

Components

Agent Node

120x44px, borde por estado (idle/running/done/error), glow al ejecutar, nombre + id

Animated Edge

Bezier SVG, particula animada en ejecucion, solido=pipeline, dashed=manual

Layout

Dagre top-to-bottom, team clusters con borde dashed, posiciones drag persistidas en DB

Toolbar

Vertical izquierda: zoom, fit, layout reset, replay (play/pause/speed/scrubber)

4

Filtering & Search

Filter Pills (flotantes)

Teams, Status, Live toggle. No-match baja a opacity 0.15. Estado en URL params.

Command Palette (⌘K)

Busca nombre, id, team, step, gate, modelo. Prefijos: team: step: gate: status:

5

Sidepanel (Agent Drawer)

420px, slide-in derecha, canvas interactivo detras. Cerrar: X / click fuera / Escape.

Tab 1: Info

Config, stats, conexiones (add/remove), modelo, params

Tab 2: Editor

Monaco Editor, markdown, save to filesystem, unsaved indicator

Tab 3: Executions

Historial, logs expandibles, stats agregados

6

Real-Time & Replay

Live (SSE)

Endpoint /api/canvas/events. Eventos: agent:started/completed/failed/output. Pill "Live" verde.

Replay

Selector de proyecto, play/pause/speed, nodos cambian progresivamente, scrubber timeline.

7

Database & API

Tablas nuevas

agent_connections (source, target, type)
agent_node_positions (agent, x, y)

8 endpoints

GET graph, PUT positions
POST/DEL connections
GET events (SSE), GET replay
GET/PUT agent file

Seed: pipeline order (brief→concept→script→...→delivery) genera conexiones automaticas.
