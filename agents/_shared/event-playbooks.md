# Event Playbooks — Events Pipeline Directive

Standardized playbooks, timelines, and checklists for events produced in the Events pipeline.

---

## Playbook 1: Webinar

**Timeline:** 2–3 weeks before event

### Timeline

| Week | Phase | Tasks |
|------|-------|-------|
| W-3 | Planning | Define topic, speakers, platform (Zoom/Teams/Riverside); set date and time; create registration page |
| W-3 | Promotion | Draft email campaign (3 sends: announce, reminder, last-call); create social assets (3–5 posts per channel) |
| W-2 | Production | Prepare slide deck (branded template); brief speakers; test platform + AV; set up Q&A and polls |
| W-2 | Promotion | Send announcement email; publish first social posts; set up paid promotion if applicable |
| W-1 | Confirmation | Send 7-day reminder email; confirm speakers; finalize run-of-show |
| W-0 (48 h) | Final checks | Send 48-hour reminder; test tech stack end-to-end; prepare backup slides |
| W-0 (24 h) | Reminders | Send 24-hour reminder; confirm recording setup |
| Event day | Execution | 30-min tech check with speakers; go live; monitor chat + Q&A; record |
| W+1 | Follow-up | Send recording + resources email (within 24 h); publish recap post; upload to on-demand library |

### Checklist

- [ ] Registration page live with UTM tracking
- [ ] Speaker agreements / bios collected
- [ ] Branded slide template applied
- [ ] Platform tested on speaker devices
- [ ] Email sequence scheduled (announce / reminder / last-call / follow-up)
- [ ] Social content calendar published
- [ ] Recording enabled and storage confirmed
- [ ] Q&A and poll questions prepared
- [ ] Run-of-show document shared with all speakers
- [ ] Recap email drafted and ready to send within 24 h post-event

## Playbook 2: Product Launch

**Timeline:** 4–6 weeks before launch

### Timeline

| Week | Phase | Tasks |
|------|-------|-------|
| W-6 | Strategy | Finalize launch date; define audience segments; set KPIs; assign cross-functional owners |
| W-6 | Messaging | Draft launch narrative, key messages, FAQ; align Legal/Product on claims |
| W-5 | Asset creation | Produce hero video, product photography, landing page copy, ad creatives, PR kit |
| W-4 | Digital setup | Build landing page; set up tracking (GA4, pixels, UTM params); configure email flows |
| W-3 | Partner / Press | Brief media partners and influencers; distribute press embargo; prepare media kit |
| W-3 | Internal | Internal briefing deck; sales enablement materials; CS/support FAQ |
| W-2 | Soft launch | Beta / early-access invite to VIP list; gather first reviews and testimonials |
| W-1 | Final prep | QA landing page and checkout; finalize ad budgets; brief paid media team |
| W-0 | Launch day | Email blast + social posts go live; PR embargo lifts; paid media activates; monitor in real-time |
| W+1 | Amplification | Retargeting campaigns; influencer amplification; case study outreach; performance review |

### Checklist

- [ ] Launch date locked and communicated cross-functionally
- [ ] Messaging hierarchy documented and approved
- [ ] Hero video and photography delivered
- [ ] Landing page QA'd on mobile and desktop
- [ ] UTM parameters and conversion tracking verified
- [ ] Email flows tested (welcome, nurture, cart/sign-up abandonment)
- [ ] Press kit distributed under embargo
- [ ] Social content bank ready (launch day + 2-week calendar)
- [ ] Paid media briefs approved and trafficking confirmed
- [ ] Internal teams briefed (sales, CS, support)
- [ ] Crisis communication plan ready (product issues, negative press)
- [ ] Day-1 performance dashboard live

## Playbook 3: Conference

**Timeline:** 8–12 weeks before event

### Timeline

| Week | Phase | Tasks |
|------|-------|-------|
| W-12 | Foundation | Confirm venue; define format (in-person / hybrid / virtual); set agenda skeleton; open speaker submissions |
| W-10 | Brand & Identity | Conference branding (name, theme, visual identity); build event website; open registration |
| W-10 | Speakers | Confirm keynotes; brief speakers on format, timing, AV requirements |
| W-8 | Sponsor & Partners | Finalize sponsorship packages; onboard sponsors; collect sponsor assets |
| W-6 | Content & Agenda | Finalize full agenda; confirm all speakers; open session scheduling |
| W-6 | Promotion | Launch paid media; outreach to media partners; influencer partnerships |
| W-4 | Production | Confirm AV/production vendor; stage design; signage and print; app / digital program |
| W-4 | Logistics | Finalize catering, A/V, seating, registration desks, badge printing, staff briefing |
| W-2 | Communications | Send full-program email to registrants; publish session previews; social amplification |
| W-1 | Final prep | Site walk-through; tech rehearsal with speakers; staff briefing; registration dry-run |
| Event | Execution | On-site registration; AV monitoring; real-time social coverage; speaker green room |
| W+1 | Post-event | Thank-you emails; recording distribution; sponsor reports; press recap; NPS survey |
| W+2 | Reporting | Final attendance and engagement report; KPI review; 2-week social amplification wrap-up |

### Checklist

- [ ] Venue contract signed; dates confirmed
- [ ] Event website live with registration
- [ ] Speaker contracts / bios / headshots collected
- [ ] Sponsorship prospectus distributed; tier packages defined
- [ ] Full agenda published (T-4 weeks)
- [ ] AV/production vendor contracted and briefed
- [ ] Branded signage and print assets to printer (T-3 weeks)
- [ ] Conference app or digital program live
- [ ] Email communication calendar (pre-event, day-of, post-event) scheduled
- [ ] Staff and volunteer roles assigned with day-of runsheet
- [ ] Recording / livestream setup confirmed
- [ ] Contingency plan for hybrid connectivity issues
- [ ] NPS / satisfaction survey prepared
- [ ] Sponsor deliverables tracking sheet live

## Universal Event Metrics

Track and report these KPIs for every event, regardless of format:

| Metric | Definition | Target (Baseline) |
|--------|------------|-------------------|
| **Registration** | Total sign-ups | — (set per event) |
| **Attendance rate** | Attendees / Registrations | ≥ 50% (webinar), ≥ 80% (in-person) |
| **Engagement rate** | Interactions (Q&A, polls, chat) / Attendees | ≥ 40% (webinar) |
| **NPS** | Post-event Net Promoter Score | ≥ 40 |
| **CSAT** | Post-event satisfaction (1–5 scale) | ≥ 4.0 |
| **Media reach** | Total impressions from PR + social | — (set per event) |
| **Social mentions** | Organic hashtag / event mentions | — (set per event) |
| **Recording views** | On-demand views within 30 days | ≥ 30% of live attendance |
| **Lead conversion** | Registrants converted to pipeline / customers | — (set per event) |
| **Cost per attendee** | Total cost / Attendees | — (set per event) |
| **ROI** | (Revenue attributed − Cost) / Cost × 100 | ≥ 0% (break-even minimum) |
