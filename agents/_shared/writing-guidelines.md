# Writing Guidelines — Writers Room Directive

Format specifications and universal rules for all copy produced in the Writers Room pipeline.

---

## Format Specifications

### Social Media Captions

| Platform | Character Range | Notes |
|----------|----------------|-------|
| Instagram | 125–150 (optimal) / up to 2,200 | Hook in first line; hashtags at end |
| Twitter / X | 50–280 | One idea per tweet; no trailing hashtags |
| LinkedIn | 150–300 (optimal) / up to 3,000 | Professional tone; line breaks for scanability |
| TikTok | 100–150 | Conversational; emojis welcome |
| Facebook | 40–80 (optimal) | Short drives more reach |

### Ad Copy

| Platform | Headline | Body | CTA |
|----------|----------|------|-----|
| Google Search | ≤30 chars (×3) | ≤90 chars (×2) | ≤15 chars |
| Meta (FB/IG) | ≤40 chars | ≤125 chars | ≤20 chars |
| LinkedIn Ads | ≤70 chars | ≤150 chars | ≤18 chars |
| YouTube Pre-roll | ≤100 chars | — | ≤20 chars |
| Display / Banner | ≤25 chars | ≤90 chars | ≤15 chars |

### Email

| Element | Length |
|---------|--------|
| Subject line | 30–60 characters (≤9 words for mobile) |
| Preview text | 40–130 characters |
| Body | 150–500 words |
| Single CTA label | 2–5 words |

**Email structure:** Greeting → Hook (1–2 sentences) → Value body (2–3 paragraphs) → CTA → Sign-off.

### Blog Articles

| Element | Specification |
|---------|--------------|
| Total length | 800–2,000 words |
| H1 (title) | 50–70 characters, includes primary keyword |
| H2 sections | 3–6 sections |
| Intro paragraph | 80–120 words |
| Conclusion | 80–150 words |
| Internal links | Minimum 2 |
| Meta description | 120–160 characters |

### AV Scripts

| Spot Length | Target Word Count | Pacing |
|-------------|------------------|--------|
| 15 seconds | ~35–40 words | Fast / energetic |
| 30 seconds | ~70–80 words | Standard |
| 60 seconds | ~140–155 words | Measured |
| 90 seconds | ~200–225 words | Narrative |

**Script format:** Scene header → Visual direction (italics) → VO / dialogue → SFX cue → End card.

### Taglines

- Length: 3–8 words
- Structure options: benefit statement, imperative, question, or rhyme/alliteration
- Must work standalone (without logo) and at full name + tagline
- Test for memorability: can someone repeat it 10 minutes later?

### Manifestos

| Element | Specification |
|---------|--------------|
| Total length | 200–500 words |
| Opening line | Single powerful sentence (≤15 words) |
| Core tension | Paragraph 1 (50–80 words): the problem / belief |
| Brand stance | Paragraph 2 (80–120 words): our answer / commitment |
| Call to belonging | Closing paragraph (40–60 words): invitation to the reader |
| Tone | First-person plural (we / us / our) |

## Universal Rules

1. **Brand DNA first.** Every piece must be traceable to the brand voice pillars defined in `brand-voice.md`. Reread them before drafting.
2. **One CTA per piece.** Do not compete for the reader's attention. Choose the single most important action.
3. **Active voice.** Prefer active constructions. Passive is acceptable only for deliberate stylistic effect.
4. **No jargon.** Write at a Grade 8–10 reading level unless the audience specification explicitly calls for technical language.
5. **Proofread.** Run a final pass for: spelling, grammar, consistency (brand name spelling, trademark symbols), and fact accuracy.
6. **Respect platform context.** Copy written for one channel should not be pasted verbatim into another without adaptation.
7. **Inclusive language.** Avoid gendered defaults, ableist idioms, and culturally insensitive references. When in doubt, consult the brand's style guide addendum.
